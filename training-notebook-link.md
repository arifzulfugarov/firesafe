# FireSafe Qwen fine-tuning notebook

Original Kaggle notebook:

https://www.kaggle.com/code/arifengine/firesafe-ai-v3-qwen-training/notebook

This code package does **not** contain an exported `.ipynb` file. To include the actual training source, download the final clean version of the notebook from Kaggle and add it to the repository as `firesafe_training.ipynb` after checking for secrets and unnecessary large outputs.

The notebook demonstrates the training and evaluation experiments. The current FireSafe model adapter is not included in this repository; it is stored in a separate private Hugging Face repository. The model should not be described as independently scientifically validated based on the training loss or small evaluation samples.
